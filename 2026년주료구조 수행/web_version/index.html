이론

스택(Stack)은 데이터를 쌓아 올리는 형태의 자료구조입니다. 접시를 쌓아 두면 가장 마지막에 올린 접시를 가장 먼저 꺼내듯, 가장 마지막에 들어간 데이터가 가장 먼저 나옵니다. 이를 LIFO(Last In First Out)라고 합니다.

네 가지 기능

PUSH데이터를 삽입
POP맨 위 데이터를 삭제
PEEK맨 위 데이터를 확인
DISPLAY저장된 데이터를 출력

꼭 기억하기

스택이 비어 있는 상태top == -1
스택이 가득 찬 상태top == SIZE - 1
SIZE가 5일 때 마지막 인덱스4
데이터 저장 방식LIFO

작동 원리

스택 크기는 5입니다. 변수 top은 가장 위에 있는 데이터의 인덱스를 가리킵니다.

Push를 눌러 숫자를 넣어 보세요.

참고: Pop은 배열의 값을 실제로 지우지 않고 top의 위치만 감소시킵니다. 그 데이터는 더 이상 스택의 일부로 취급되지 않을 뿐입니다.
